## How to use it

Choose **Link or text** and type what the code should open, or choose **Wi-Fi network** and enter the network name and password so guests can join by pointing their camera. Adjust the size and colours, then download the image. The code is drawn on your device and does not expire, because the information is in the pattern itself and not on a server.

## Getting a code that scans first time

- Keep strong contrast, with a dark code on a light background. Inverted and pale codes fail on many phones.
- Leave the blank margin around the code. Scanners need it to find the edges.
- Shorter content makes a simpler code that scans from further away. Use a short address where you can.
- For print, raise the error correction to High so the code survives creases and scuffs.
- Always test with at least two phones before you print a batch.

## Questions people ask

### Do these codes stop working?

No. They are static. They work for as long as the link they point to works.

### Can I track how many people scan it?

Not from the code itself. Point it at a link with campaign tags from the [UTM link builder](../utm-builder/) and your analytics will count the visits.

### Are QR codes safe?

The code is only a way to type a link quickly. Treat the link with the same care as any other. The [QR code guide](../../guides/how-qr-codes-work/) explains what to check.
