## How to use it

Use the picker or type a colour as a HEX code, an `rgb()` value or an `hsl()` value. All four formats update together, and each has its own copy button.

## The formats

- **HEX** is three pairs of hexadecimal digits for red, green and blue. It is the most common format in web design.
- **RGB** is the same three amounts as ordinary numbers from 0 to 255.
- **HSL** describes a colour by hue, saturation and lightness. It is the easiest format to adjust by hand: change the last number to make a lighter or darker version of the same colour.
- **CMYK** is the cyan, magenta, yellow and black ink mix used in printing. Screens and printers produce colour differently, so treat the CMYK values as a starting point and check a printed proof.

## Questions people ask

### Why does my colour look different in print?

Screens add light and ink absorbs it, and screens can show bright colours that ink cannot reproduce.

### What does a three digit HEX code mean?

It is shorthand. Each digit is doubled, so `#3af` is the same as `#33aaff`.
