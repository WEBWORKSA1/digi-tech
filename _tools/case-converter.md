## How to use it

Paste your text, press the style you want and copy the result. Your original stays in the top box so you can try another style straight away.

## The styles

- **Title Case** capitalises the first letter of each word, for headings.
- **Sentence case** capitalises only the first word of each sentence, which is easier to read in long text.
- **camelCase** joins words and capitalises all but the first. It is common for variable names in JavaScript and Java.
- **snake_case** joins words with underscores, as used in Python and in database column names.
- **kebab-case** joins words with hyphens, the standard for web addresses and CSS class names.

## Questions people ask

### I typed a whole paragraph with Caps Lock on. Can this fix it?

Yes. Paste it in and press **Sentence case**.

### Which style is best for a web address?

Lowercase words joined by hyphens. Search engines read hyphens as word breaks, and lowercase avoids duplicate addresses that differ only by capital letters.
