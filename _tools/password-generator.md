## How to use it

Drag the length slider, tick the kinds of characters the site allows, and copy the result. Each press of **Generate another** draws fresh random characters from your device's cryptographic random number source, the same one your browser uses for secure connections.

## What makes a password strong

Strength comes from two things: how many characters there are, and how many different characters each position could hold. The tool reports this as bits of randomness. Every extra bit doubles the number of guesses an attacker needs. A 20 character password using all four character types carries about 130 bits, far beyond what any computer can search.

Length beats complexity. Going from 12 to 16 characters adds more strength than adding symbols to a short password.

## Questions people ask

### Is it safe to generate a password on a website?

Here, yes. The password is created by code running on your own device and is never sent over the network. You can load the page, switch off your connection and it still works.

### How long should a password be?

Use at least 14 characters for accounts that matter, and 20 or more where a password manager types it for you. See the [strong passwords guide](../../guides/strong-passwords/) for the full reasoning.

### How do I remember passwords like these?

You do not. Store them in a password manager and remember one long passphrase that unlocks it. Then add [two-factor authentication](../../guides/two-factor-authentication/) to the accounts that offer it.
